# Componentes Frontend - PerfumerIA

Esta carpeta contiene los componentes frontend de la plataforma **PerfumerIA**.

---

## Componentes
- [Web App](./web-app): Aplicación principal tipo SPA basada en React + Vite.

---

## Características
- Diseño minimalista y profesional (Blanco/Negro/Gris).
- Logo dorado integrado.
- Sistema de navegación basado en roles (RBAC).
- Carrito de compras funcional con simulación de pago.
- Vistas personalizadas de Perfil y Administración.
- Catálogo de productos con imágenes únicas y relevantes.

---

## Estándar
- Gestión de dependencias: NPM
- Herramienta de construcción: Vite 5
- Biblioteca UI: React 18
- Testing: Vitest y Testing Library
